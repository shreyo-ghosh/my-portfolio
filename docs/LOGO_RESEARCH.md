# Logo research — studios & implications for LaunchLayer

## Studios reviewed
| Studio | Notable work | Pattern to steal |
|--------|--------------|------------------|
| [Pentagram](https://www.pentagram.com/) | Oxide, Tractable, Graphcore, MIND, Secondmind | Metaphor in the mark; dark as technical canvas; one accent; motion |
| [Saffron](https://saffron-consultants.com/) | AlphaSense, Bittensor, Amazon Ads | Radical simplicity, quiet confidence, modular systems |
| [Collins](https://www.wearecollins.com/) | Spotify, Figma, Mailchimp | Bold personality, strategy-first transforms |
| [Smith & Diction](https://smithdiction.substack.com/p/branding-perplexity-ai-70eb2cb2ef48) | Perplexity | Encode the differentiator (asterisk = citations) |
| Vercel / Linear playbook | Triangle / L | Extreme constraint; favicon + 1-color + motion tests |

## What failed in v1 (white options)
- White canvas reads “generic stock logo,” not AI infra
- Too many interchangeable geometric marks without a *story*
- Low engagement for LinkedIn avatar (dark products need dark marks)

## LaunchLayer encoding rule
**Launch through Layer** = ship into production infrastructure  
- Amber = voltage / ship  
- Teal = reliability / layer  
- Void = focus  

Avoid: rockets, clouds, gears, purple neon, soft AI blobs.
