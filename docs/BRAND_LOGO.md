# LaunchLayer brand mark — Radial Asterisk (selected)

## Concept
Four amber blades radiate from a teal core — an asterisk of **multi-agent launch** through layers of the business. Inspired by Perplexity’s “encode the differentiator” craft (Smith & Diction): the mark *is* the idea of agents shipping outward from a reliable center.

- **Amber blades** = launch / voltage / action  
- **Teal core** = reliability / AIRE / production node  
- **Void black** = focus / technical canvas
